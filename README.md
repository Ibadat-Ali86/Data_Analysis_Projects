## 🦠 COVID-19 Data Analytics Platform

**[View Project →](COVID19-Data-Analytics-Platform/)**

Comprehensive full-stack pandemic analytics platform analyzing 209 countries from 2020-2021.

### Highlights
- 📊 **2,793 monthly records** processed across 6 continents
- 🔬 **10 business problems** solved with statistical analysis
- 🚀 **Automated ETL pipeline** with MySQL data warehouse
- ⚡ **FastAPI backend** with 15+ REST endpoints
- 📱 **React dashboard** with interactive visualizations
- 🐳 **Docker deployment** for one-command setup
- 📈 **20,000+ word insights** documentation

### Tech Stack
\`Python\` \`FastAPI\` \`React\` \`TypeScript\` \`MySQL\` \`Docker\` \`Jupyter\` \`Pandas\` \`Plotly\` \`Seaborn\`

### Key Features
- Disease spread pattern analysis
- Healthcare capacity optimization
- Vaccination effectiveness tracking
- Policy impact assessment
- Demographic risk analysis
- Time series forecasting
